# Self-hosted variable fonts

These unmodified Latin, normal-style variable WOFF2 files are used with `next/font/local` so production builds do not fetch fonts from Google at build time. They preserve the existing Bodoni Moda and Inter families and their weight axes; no font package is installed as an application dependency.

- `bodoni-moda-latin-wght-normal.woff2` — Bodoni Moda, variable weight 400–900; source package `@fontsource-variable/bodoni-moda@5.3.0`, source font version v28, from Google Fonts. Copyright 2020 The Bodoni Moda Project Authors. See `OFL-Bodoni-Moda.txt`.
- `inter-latin-wght-normal.woff2` — Inter, variable weight 100–900; source package `@fontsource-variable/inter@5.3.0`, source font version v20, from Google Fonts. Copyright 2016 The Inter Project Authors. See `OFL-Inter.txt`.

Both source packages declare the SIL Open Font License 1.1. Their complete license texts are retained alongside the font files. The font binaries were not modified.
