\# MR.KCRONUS Visual Design



You are working on a premium fashion-art direction project.



Before making visual decisions, inspect the actual supplied assets.



\## Source of Truth



The canonical MR.KCRONUS logo is authoritative.



Never recreate it from memory.



Never approximate its geometry.



Never distort it.



Never replace it with generated artwork.



If an animation requires separate logo components and the supplied asset is a flat raster, determine whether controlled decomposition is technically safe before proceeding.



\## Visual Principles



Prefer:



\- negative space

\- asymmetry

\- editorial scale

\- architectural framing

\- restrained typography

\- controlled depth

\- precise alignment

\- deliberate composition

\- subtle materiality



Avoid:



\- generic cards

\- excessive rounded corners

\- excessive gradients

\- neon

\- gaming HUDs

\- decorative particles

\- generic glassmorphism

\- template-like ecommerce grids



\## Color



Obsidian #050505

Ivory #F5F5F0

Stone #5F5F5A

Antique Gold #A89B7A



Gold is an accent, not a dominant color.



\## Composition



Prefer:



\- large visual masses

\- strong negative space

\- asymmetric layouts

\- architectural framing

\- layered depth



Do not fill empty space simply because it exists.



\## Typography



Use typography as composition.



Avoid excessive font weights and font families.



\## Editorial Rule



Every section should feel like part of the same world.



Do not design each section as an independent UI component.



The transition between sections matters as much as the section itself.
